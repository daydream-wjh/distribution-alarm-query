# 配电网告警快速查询与信息筛选辅助工具

面向配网调度与配网自动化岗位的**单文件网页工具**：把配网自动化主站里步骤多、告警杂的告警查询流程，压缩成"选时间 → 选表 → 点查询"三步。

整个工具就是 `index.html` 一个文件（约 2300 行，无构建、无依赖安装），双击即可打开，也可以直接放到任意静态服务器上。

> 因为浏览器跨域限制，从 `file://` 直接打开时无法请求内网接口。实际使用时把 `index.html` 放到与告警接口同源的静态目录（例如主站 Web 目录）下访问，或给接口加上 CORS 头。

---

## 解决的三个问题

| 原来 | 现在 |
| --- | --- |
| 要先选数据库、再一步步设时间范围和查询条件，不常操作的人容易卡住 | 默认时间范围已设好，常用区间一键切换（近 1 / 12 / 24 小时） |
| 五种告警表分散在不同入口，查一次要来回切 | 表选择、时间、筛选条件在同一屏内完成，选择结果自动记住 |
| 查回来的告警混在一起，做 FA 动作分析要人工挑开关动作、保护动作 | 支持按字段逐条添加筛选条件，条件组合可保存复用 |

## 主要功能

### 查询
- 支持 5 张告警表：

  | 表名 | 含义 |
  | --- | --- |
  | `da_process_info` | DA 过程信息 |
  | `dms_rl_yx_warn` | 配网二次遥信 |
  | `dms_op_ctrl` | 配网控制操作 |
  | `dms_accident_info` | 配网事故 |
  | `dms_yx_bw` | 配网遥信变位 |

- 时间范围：日历选择器 + 快捷区间（近 1 小时 / 近 12 小时 / 近 24 小时 / 此刻），也支持手工输入。
- 筛选条件：可动态增删条件行（字段 / 运算符 / 值），支持保存、恢复、清除；与表选择、显示设置一起存在浏览器 localStorage 里，换浏览器或换文件路径后需要重新保存。

### 结果处理
- 分页展示，默认每页 500 条，可在「显示设置」里调整并保存。
- 导出 Excel（走 CDN 上的 SheetJS）；内网访问不到 CDN 时自动降级为 CSV 导出。
- 全量导出：逐页拉取所有结果后再合成文件，中途可取消（不会生成不完整的文件）。
- **查看原始响应 / 复制完整响应 / 复制请求 XML / 复制 curl 命令**——排查接口问题时很有用。
- **导入响应**：把一段已经拿到的响应文本（XML / JSON / 纯文本分隔）粘进去直接解析预览，不需要重新发起查询。仓库里的 `模拟告警响应-30条.xml` 可以直接用来试这个功能。

### 解析容错
接口返回的形态在不同版本主站上并不统一，工具做了多层兜底：
`unwrapResponseText` → `parseXmlTextEnvelope` → `parseXmlResponse` / `parseTextResponse`，能处理「XML 外壳里再包一层分隔符文本」「JSON 包 XML」「纯 `|` / `@` 分隔文本」等情况。

## 快速开始

```bash
git clone https://github.com/daydream-wjh/distribution-alarm-query.git
cd distribution-alarm-query
open index.html          # macOS；Windows 直接双击
```

不接后端也能完整体验界面：点「导入响应」，把 `模拟告警响应-30条.xml` 的内容贴进去 → 「解析预览」。

## 接入你自己的告警接口

接口地址**没有写死**，三种方式任选其一（优先级从高到低）：

1. 同目录放一个 `config.local.js`：
   ```js
   window.ALARM_API_URL = 'http://你的地址:端口/web_alarm_query/warnqueryservlet';
   ```
   然后在 `index.html` 的 `<head>` 里加一行 `<script src="config.local.js"></script>`。
2. 浏览器控制台执行一次：
   ```js
   localStorage.setItem('alarmApiUrl', 'http://你的地址:端口/web_alarm_query/warnqueryservlet')
   ```
3. 直接改 `index.html` 里的 `DEFAULT_API_URL`。

请求体是 XML，格式可以在界面上点「查看请求 XML」看到，也可以「复制 curl 命令」直接在终端里复现。

## 已知限制

- **跨域**：`file://` 打开时请求内网接口会被浏览器拦。需要同源部署或接口侧放行 CORS。
- **Excel 导出依赖 CDN**：离线的内网环境会退回 CSV（功能不受影响，只是格式不同）。
- **localStorage 与路径绑定**：保存的筛选条件、表选择、显示设置按「文件路径 + 浏览器」隔离，换一处打开就看不到之前的保存。
- **单文件形态**：所有样式和逻辑都内联在 `index.html` 里，改起来方便（拷一个文件就能跑），但不适合多人协作开发。

## 说明

- 仓库里的 `模拟告警响应-30条.xml` 是**完全虚构的样例数据**（"示例站 / 10kV示例1线 / 101开关"），不含任何真实站点或设备信息。
